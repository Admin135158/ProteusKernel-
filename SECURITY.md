# Security Policy

## Supported Versions

We currently support the following versions of Zayden-AI with security updates:

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within Zayden-AI or any of its dependencies, please **do not** disclose it publicly until we have had a chance to address it.

Please report vulnerabilities to:

**Fernaaathebeast@gmail.com**

You should receive a response within 48 hours. We will work with you to validate and fix the issue, and we will give you credit for the responsible disclosure.

## Responsible Disclosure Policy

- Please provide a detailed description of the vulnerability.
- Include steps to reproduce, affected versions, and potential impact.
- We ask that you allow us 90 days to resolve the issue before any public disclosure.
- We will publicly acknowledge your contribution once the fix is released.

## Security Best Practices for Users

- Always run the latest stable version.
- Keep your API keys and secrets in `.env` and never commit them.
- Use the Digital Bodyguard module to monitor agent behavior in production.
- Review HOLO audit logs regularly to detect anomalous activity.

## Acknowledgements

We thank the security community for helping keep Morpheus Innovations software safe.
